## 5. Security/safety decisions worth remembering

- Customers can't change their own plan (only via Stripe payment); manual plan changes are
  staff-only (`AUTOFLOW_STAFF_EMAILS`).
- Mandatory approvals (sending email) can't be disabled by workflows or the AI builder.
- `.env` credentials (Airtable) are only used by the local CLI workspace — never by tenants.
- Tests blank all real credentials, so no test can call Gemini/Claude/Airtable/Gmail.
- Production refuses to start without secret keys, PostgreSQL and https.
